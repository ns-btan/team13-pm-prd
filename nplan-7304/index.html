    NPLAN-7304 — Event Streaming Client — Artifactory Support Active¶

    Status: Active · Phase: Concept · Version: 1.8 · Domain: Event Streaming Client / Deployment · Owner: @ns-btan · Updated: 2026-05-12

    Enables Event Streaming Client to pull Docker images through a customer-managed JFrog Artifactory repository instead of directly from Docker Hub, unblocking deployment in air-gapped and security-restricted enterprise environments where direct public registry access is prohibited.
